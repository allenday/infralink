# Infralink v0.6.3

This patch release makes static host adoption checks consume the registry's
strict V2 service catalog directly. `infralink doctor host <ref> --validate`
now compiles a host-scoped V2 declaration inventory without legacy observation
plan inputs, and fails closed on invalid or non-V2 catalog documents.

The command remains read-only: it does not contact the host, render services,
request reconciliation, or consult live observer evidence.
