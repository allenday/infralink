# Infralink v0.5.5

Infralink `v0.5.5` repairs the ES2 bootstrap execution path.

## Bootstrap Execution

- The local host wrapper preserves standard input when a bootstrap apply uses
  `--bws-token-stdin`.
- Controller bootstrap materializes the management source from the controller
  image rather than requiring an absent immutable management revision.
- Bootstrap remains fail-closed for registry, SSH/Tailnet identity, and BWS
  access requirements.

## Release Evidence

Woodpecker is the sole release executor. A manual release whose commit equals
`main` requires `RELEASE_VERSION=0.5.5` and publishes the wheel, sdist,
checksums, and Cosign bundle to GitHub.
