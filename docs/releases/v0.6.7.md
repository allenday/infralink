# Infralink v0.6.7

This patch release preserves a manifest-declared SSH host-key algorithm during
host apply. A declared `ssh-ed25519` pin now constrains `ssh-keyscan` to
ED25519 before Infralink writes the temporary pinned `known_hosts` file.

Legacy operations contracts that contain only a SHA-256 fingerprint retain
their existing all-type scan until their host pins are migrated to the
manifest form.
