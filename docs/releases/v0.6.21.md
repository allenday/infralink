# Infralink v0.6.21

This release publishes the non-runnable `infralink.fleet-prometheus-evidence/v1`
artifact contract. It provides strict semantic validation, a portable JSON
Schema, deterministic signed bytes, bounded freshness rules, and Ed25519
verification support for the private controller producer and later read-only
fleet validator. It adds no Prometheus client, credentials, CLI command, or
MCP operation.
