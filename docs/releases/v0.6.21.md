# Infralink v0.6.21

This release publishes the non-runnable `infralink.fleet-prometheus-evidence/v1`
artifact contract. It provides strict semantic validation, a portable JSON
Schema, deterministic signed bytes, bounded freshness rules, and Ed25519
verification support for the private controller producer and later read-only
fleet validator. It adds no Prometheus client, credentials, CLI command, or
MCP operation.

It also makes the existing public `infralink` command extensible through typed
runtime command plugins without adding another executable. Mounted commands
inherit root-owned registry and edge sources in both CLI and native MCP; YAML
remains the CLI default and MCP retains JSON transport output. Built-in command
options remain authoritative even where historical package metadata advertises
the same name.
