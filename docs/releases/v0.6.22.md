# Infralink v0.6.22

This patch adopts `agent-surface>=0.1.7` for installed public operation
packages. Their build-generated manifests are now the single import-free source
for root help and native MCP discovery. An explicit invocation imports and
verifies the selected app against that same manifest before it runs.

Discovery is scoped to one CLI or MCP enumeration, so an upgraded installed
package is visible to the next request without retaining stale schemas in a
long-lived MCP server. YAML remains the CLI default and MCP retains the
canonical `infralink.cli/v1` structured envelope.
