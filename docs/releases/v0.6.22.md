# Infralink v0.6.22

This release makes the public `infralink` command tree extensible through
typed runtime command plugins without adding a second executable. It keeps
YAML as the default CLI output, projects root-owned registry and edge sources
through native MCP tools, and prevents mounted commands from creating local
output or source selectors.

The release also distinguishes built-in commands from historical package entry
points, so existing commands such as `diagram` retain their established
options. It does not change host reconciliation behavior.
