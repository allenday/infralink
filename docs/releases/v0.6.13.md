# Infralink v0.6.13

This patch release adds typed V2 artifact delivery contracts. A service profile
declares the safe file or tree destinations and lifecycle expected by a
component; an instance binds immutable Registry-relative artifact sources with
their SHA-256 digests.

The release validates paths, ownership, modes, source uniqueness, and tree
members before an Ops materializer acts. It does not introduce product-specific
Gatus, Grafana, or RelayOS controller behavior, and it does not alter deployed
host state by itself.
