# Infralink v0.5.3

Infralink `v0.5.3` makes the fail-closed bootstrap plan actionable when the
host machine BWS token is the only remaining prerequisite.

## Bootstrap Apply Handoff

- A read-only `infralink host bootstrap` result advertises one HATEOAS
  `apply` action only when all other required readiness checks pass.
- The action provides the exact explicit apply command and pipes
  `$HOST_BWS_TOKEN` to `--bws-token-stdin`; no token value is included in the
  command envelope.
- Other failed prerequisites omit the apply handoff. Bootstrap remains pinned
  to the declared Tailnet address and requires explicit `--apply` for mutation.

## Compatibility

- Python 3.10, 3.11, and 3.12 on supported POSIX/Linux systems.
- Existing release tags and artifacts remain immutable historical records.

## Release Evidence

Woodpecker is the sole release executor. A manual release whose commit equals
`main` requires `RELEASE_VERSION=0.5.3`, verifies the protected `main` SHA,
and publishes the wheel, sdist, checksums, and Cosign bundle to GitHub.
