# Infralink v0.5.2

Infralink `v0.5.2` completes the fail-closed operator bootstrap contract for
declared Tailnet controller hosts.

## Operator Bootstrap Contract

- `infralink host bootstrap` requires an explicit Tailnet IPv4 address and
  rejects an address that does not match the declared host.
- Bootstrap application requires the host machine BWS token on standard input;
  the token is neither an option value nor a registry field.
- The CLI derives its bounded executor request only from the declared host
  controller bootstrap state. Missing controller inputs, unavailable executor
  capabilities, SSH transport failures, and failed remote bootstrap steps stop
  with typed remediation.
- Planning remains read-only. Mutation requires the explicit `--apply` request
  and is limited to the declared bootstrap executor.

## Compatibility

- Python 3.10, 3.11, and 3.12 on supported POSIX/Linux systems.
- The canonical registry checkout remains `/var/lib/infralink/registry`.
- Existing release tags and artifacts remain immutable historical records.

## Release Evidence

Woodpecker is the sole release executor. A manual release whose commit equals
`main` requires
`RELEASE_VERSION=0.5.2`, verifies that its commit equals protected `main`, and
publishes the wheel, sdist, checksums, and Cosign bundle to GitHub.
