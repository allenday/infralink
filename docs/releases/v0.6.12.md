# Infralink v0.6.12

This patch release adds typed, profile-owned non-secret configuration slots to
the observation v2 contract. A service instance binds each required slot once,
with finite scalar, record, or repeated-record shapes validated against the
selected profile.

The release provides deterministic public configuration projections for generic
Ops renderers, source-addressable diagnostics, and no-secret typed support for
RelayOS tenant hostname maps. It does not add product-specific controller
behavior or alter deployed host state.
