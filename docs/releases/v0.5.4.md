# Infralink v0.5.4

Infralink `v0.5.4` makes incomplete controller bootstrap declarations directly
actionable for operators.

## Controller Bootstrap Diagnostics

- `infralink host bootstrap` reports the exact host manifest and deployment
  paths when it cannot resolve canonical controller bootstrap state.
- The structured failure lists each required manifest and deployment field,
  including the conditional controller image branch selector.
- The failure advertises a safe, read-only `host show` action for inspecting
  the affected host declaration. Bootstrap remains fail-closed and does not
  write registry state.

## Compatibility

- Python 3.10, 3.11, and 3.12 on supported POSIX/Linux systems.
- Existing release tags and artifacts remain immutable historical records.

## Release Evidence

Woodpecker is the sole release executor. A manual release whose commit equals
`main` requires `RELEASE_VERSION=0.5.4`, verifies the fetched `main` SHA,
and publishes the wheel, sdist, checksums, and Cosign bundle to GitHub.
