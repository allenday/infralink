# Infralink v0.5.1

Infralink `v0.5.1` packages the already-merged operator host workflow:
`infralink host create`, `host list`, `host show`, `host bootstrap`, `host
apply`, and `operation status`. Every command continues to emit one
`infralink.cli/v1` envelope in YAML by default.

## Compatibility

- Python 3.10, 3.11, and 3.12 on supported POSIX/Linux systems.
- Existing release tags and artifacts remain immutable historical records.
- The host-side controller image invokes this CLI through its public wrapper;
  the host registry checkout remains `/var/lib/infralink/registry`.

## Release Evidence

Woodpecker is the sole release executor. A manual release on `main` requires
`RELEASE_VERSION=0.5.1`, verifies that its commit equals protected `main`, and
publishes the wheel, sdist, checksums, and Cosign bundle to GitHub.
