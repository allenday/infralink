# Infralink v0.5.6

Infralink `v0.5.6` adds typed profile-scoped metrics operations views.

## Operations Views

- `profile_metrics` derives its member services and hosts from every declared
  instance of a metrics-capable service profile.
- The projection requires a metrics datasource and retains view, profile, and
  service-instance provenance for operator inspection.
- This supports reusable dashboards such as fleet-wide NGINX without a
  hard-coded host membership list.

## Release Evidence

Woodpecker is the sole release executor. A manual release whose commit equals
`main` requires `RELEASE_VERSION=0.5.6` and publishes the wheel, sdist,
checksums, and Cosign bundle to GitHub.
