# Infralink v0.3.0

Infralink `v0.3.0` publishes the immutable publisher v2 contracts for release
requests and attestations. The release preserves the stable read-only topology
API and machine-oriented CLI introduced in `v0.2.0`.

## Compatibility

- Python 3.10, 3.11, and 3.12 on supported POSIX/Linux systems.
- Every CLI invocation emits one `infralink.cli/v1` JSON envelope.
- Release request and attestation v2 schemas are public, deterministic, and
  contain no registry credentials, private topology, or secret values.
- Existing v0.2 release artifacts and tags remain immutable historical records.

## Release Evidence

Woodpecker is the sole build and release executor. A manual release runs for
`main` on Python 3.12 after the parallel Python 3.10-3.12 quality gates. It
requires the requested and package versions to equal `0.3.0`, verifies that the
pipeline commit is the current `main` commit, and stops if tag or release
`v0.3.0` already exists.

The GitHub release contains exactly:

```text
infralink-0.3.0-py3-none-any.whl
infralink-0.3.0.tar.gz
SHA256SUMS
SHA256SUMS.sigstore.json
```

The checksum file covers the wheel and sdist in canonical order. The Cosign
bundle signs that checksum file with the Woodpecker release key. The manual
release continues to use the repository's Woodpecker-only release step; it
does not add GitHub Actions, GHCR, a fleet deployment, registry mutation, or
PyPI upload.

## Adoption And Rollback

Consumers record the release tag, source commit, and wheel digest before
adoption. Rollback restores the previously verified consumer revision and
digest; it does not rebuild old source or mutate the existing `v0.2.0` or
`v0.3.0` release records.
