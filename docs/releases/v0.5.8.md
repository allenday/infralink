# Infralink v0.5.8

Infralink `v0.5.8` fixes configured registry checkout resolution for the
operator CLI and native MCP transport.

## Doctor Source Resolution

- `doctor` accepts either a registry checkout root or its direct `hosts/`
  catalog path.
- Host manifests and deployment contracts are resolved consistently from the
  canonical `hosts/<uuid>/` catalog.
- Standard observation companions derive from the checkout root without
  falling back to example inputs.
- Doctor requires the canonical manifest SSH host-key binding before reporting
  an active desired-state declaration ready, even when legacy apply metadata is
  present for compatibility.

## Release Evidence

Woodpecker is the sole release executor. A manual release whose commit equals
`main` requires `RELEASE_VERSION=0.5.8` and publishes the wheel, sdist,
checksums, and Cosign bundle to GitHub.
