# Infralink v0.6.9

This patch release publishes the first typed controller-adapter boundary for
the public operational runtime split. The request binds an adapter to the
exact checked-out registry revision, host UUID, runtime roots, and execution
phase. The result carries only bounded sanitized action and evidence summaries.

The contract keeps generic controller mechanics portable while private
environment adapters retain profile rendering, provider configuration, and
service-specific policy. No host deployment behavior changes in this release.
