# Infralink v0.6.4

This patch release adds the public, offline
`infralink.observation.project_v2_metric_contracts` API. It accepts explicit
strict V2 source paths, preserves source provenance, and produces the existing
normalized component metric contracts for generic adapter consumers.

The API fails closed for empty, malformed, and non-V2 source sets. It has no
provider, renderer, controller, or deployment side effects.
