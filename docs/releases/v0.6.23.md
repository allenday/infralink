# Infralink v0.6.23

This release expands the canonical Agent Surface projection for host, edge,
analysis, and documentation reads while retaining YAML as the CLI default.

`infralink host status` now reads the declared target's existing reconcile
evidence portably on mawk-based hosts, caps that runtime-evidence read, and
does not invent a next-run timestamp when systemd cannot provide one. CLI and
MCP continue to project the same canonical operation envelope.
