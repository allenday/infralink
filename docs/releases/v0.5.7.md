# Infralink v0.5.7

Infralink `v0.5.7` adds native Model Context Protocol transport for the
existing typed CLI.

## MCP Transport

- `infralink mcp serve` exposes one `infralink_command` tool over stdio.
- The tool delegates to the existing CLI in process, forces structured JSON,
  and preserves the CLI envelope as MCP structured content.
- Existing HATEOAS commands and explicit `--write` / `--apply` gates remain
  the only operator and mutation interface; the transport adds no shell or
  deployment path.

## Release Evidence

Woodpecker is the sole release executor. A manual release whose commit equals
`main` requires `RELEASE_VERSION=0.5.7` and publishes the wheel, sdist,
checksums, and Cosign bundle to GitHub.
