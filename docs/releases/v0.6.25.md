# Infralink v0.6.25

This release publishes the typed public operator surface merged in #270. The
single Infralink operation registry now projects both the YAML-first CLI and
native MCP, with generated parser errors and HATEOAS actions sharing the same
contracts.

The published runtime now requires `agent-surface[mcp]>=0.2.3,<0.3`. This
includes canonical parse envelopes and redaction of unknown option values.
